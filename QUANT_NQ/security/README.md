# security — مخزن الأسرار المشفّر

حزمة **خارج النواة تماماً**. `core/` لا يستوردها ولا يذكر اسمها، وحذف
هذا المجلد كاملاً يُبقي النواة تعمل كما هي. هذا مُختبَر آلياً في
`tests/security/test_vault.py::test_core_does_not_know_security_exists`.

## الاستعمال من داخل ذرة

```python
from security import get_secret_provider

token = get_secret_provider().get_secret("telegram_bot_token")
if not token:
    self._log.warning("لا توكن — أعمل بلا اتصال")
```

الذرة لا تعرف Fernet، ولا الملفات، ولا متغيرات البيئة. تعرف اسم سرّها فقط.

## الإعداد لأول مرة

```bash
pip install -e ".[security]"

python3 scripts/secrets_admin.py init          # يطلب عبارة مرور مرتين
python3 scripts/secrets_admin.py set telegram_bot_token
python3 scripts/secrets_admin.py list          # أسماء المفاتيح فقط
python3 scripts/secrets_admin.py check         # فحص بلا كشف
python3 scripts/secrets_admin.py rotate        # تغيير العبارة و salt
```

## مصادر المفتاح — بترتيب الأفضلية

| المصدر | متى | الأمان |
|---|---|---|
| **DPAPI** (ويندوز) | خدمة تعمل تلقائياً | مربوط بحساب المستخدم والجهاز |
| **عبارة مرور** | تشغيل تفاعلي | لا شيء دائم على القرص |
| **متغير بيئة** | تطوير/حاويات | ⚠️ سرّ دائم — تحذير في السجل |

`QUANT_MASTER_KEY` يقبل صيغتين: مفتاح Fernet جاهز، أو `pass:<عبارة>`
فيُشتق منها المفتاح بنفس معاملات المخزن.

## الحالات

| الحالة | المعنى | سلوك `get_secret` |
|---|---|---|
| `available` | جاهز | يُرجع القيمة |
| `locked` | المخزن موجود، المفتاح لا | `None` |
| `unavailable` | لا مخزن أو تعذّرت قراءته | `None` |
| `cleared` | فُرِّغ بعد الإيقاف | `None` |

**لا يرمي استثناءً في أي حالة.** غياب السر قرار الذرة لا قرار النظام
(المادة 27/81).

## ما لا تضمنه هذه الحزمة

- **محو الذاكرة ليس مطلقاً.** بايثون لا يضمن إزالة كل نسخة: قد تكون
  نُسخت أثناء إعادة تخصيص، أو كُتبت في ملف المبادلة (swap). `wipe()`
  يقلّل نافذة التعرّض ولا يلغيها.
- **من يقرأ ذاكرة العملية يقرأ الأسرار.** التشفير يحمي القرص، لا
  عملية قيد التشغيل. الحماية من ذلك مسؤولية نظام التشغيل.
- **عبارة مرور ضعيفة تُهزم بالتخمين دون اتصال.** الملف بحوزة المهاجم
  يعني محاولات غير محدودة. Argon2id يبطّئ ذلك ولا يمنعه.

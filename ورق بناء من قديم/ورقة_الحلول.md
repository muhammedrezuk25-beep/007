**لا ذرّة جديدة.** كل ذرّة تعلن نبضتها في مخرَجها الموجود أصلًا:

```
كل ذرّة تنشر شيئًا  →  الناقل يرى النشر  →  999 المسبار يعدّ
كل ذرّة صامتة       →  تنشر atom.alive كل N ثانية
```

**والأنظف: ذرّة واحدة تراقب الناقل نفسه.**

```
ذرّة جديدة — رقم حرّ في 750
  تسمع:  كل حدث (اشتراك شامل عبر الإعداد)
  تبني:  جدول {atom_id: آخر نشر}
  تنشر:  tools.atoms.silence  عند تجاوز الحدّ
```

**فتصير: «103 لم ينشر منذ 40 ثانية» بدل «103 يقول إنه سليم».**

**العمل:** ذرّة واحدة · ~150 سطرًا.

**يرفع:** نبضة الذرّات 0 → 90%

**+6.0 نقاط**

### ح-1.2 · الأثر المترابط

**الحلّ الأول — سطران في النواة (بند كسر تجميد):**

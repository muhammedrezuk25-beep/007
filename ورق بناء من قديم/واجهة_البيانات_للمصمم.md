# واجهة البيانات — لمصمّم اللوحة

**QUANT_NQ · 2026-08-01**

**هذا الملف يصف ما يخرج من النظام. التصميم والتخطيط والألوان ليست فيه —
هي شغلك.**

---

## نقطتان اثنتان

النظام يشغّل خادمًا محلّيًّا على المنفذ المضبوط في إعداد الذرّة 850
(الافتراضي `8850`).

```
GET  /state     لقطة كاملة، مرّة واحدة              → JSON
GET  /events    تدفّق مفتوح، يُدفَع عند كل تغيير     → Server-Sent Events
```

**كلاهما مفتوح لأي أصل (`Access-Control-Allow-Origin: *`)، فتفتح صفحتك من
ملف محلّي أو منفذ آخر بلا إعداد.**

**والخادم يستمع على الحلقة المحلّية وحدها — لا يُرى من خارج الجهاز.**

---

## `GET /state` — اللقطة

```json
{
  "generated_at": 1785686270.237,
  "live": 4,
  "total": 33,
  "expected": ["market_data.unified", "risk.unified", "..."],
  "events": {
    "platform.terminal_state": {
      "payload": { "connected": true, "trade_allowed": true,
                   "expert_allowed": true, "bridge_beat": 1785686270.237 },
      "source": "619",
      "seen_at": 1785686270.237,
      "age_s": 0.4
    }
  }
}
```

| الحقل | المعنى |
|---|---|
| `generated_at` | زمن اللقطة — **من الساعة الرسمية للنظام لا من ساعة الجهاز** |
| `live` | كم حدثًا وصل فعلًا |
| `total` | كم حدثًا ينتظره النظام |
| `expected` | أسماء كل الأحداث المنتظَرة — **الغائب منها معلومة بذاته** |
| `events[name].payload` | الحمولة كما وصلت |
| `events[name].source` | رقم الذرّة الناشرة |
| `events[name].seen_at` | متى وصلت |
| `events[name].age_s` | عمرها بالثواني — **قيمة بلا عمر لا تُقرأ** |

**`age_s` قد يكون `null` قبل وصول أوّل نبضة ساعة. اعرضه «—» لا صفرًا.**

## `GET /events` — التدفّق

اتصال واحد يبقى مفتوحًا. كل تغيير يُدفَع فورًا، والصفحة لا تُعاد تحميلها.

```js
const es = new EventSource("http://127.0.0.1:8850/events");
es.onmessage = (ev) => {
  const frame = JSON.parse(ev.data);
  // frame.panels : ما تغيّر
  // frame.stats  : الأرقام العلوية
};
es.onerror = () => { /* انقطع — المتصفّح يعيد المحاولة تلقائيًّا */ };
```

**الدفع مخنوق بفاصل أدنى (`min_push_interval_s`) لأن تيّار التكّات أسرع
ممّا تقرأ عين.**

**والبنية المقترَحة: `/state` مرّة عند الفتح، ثم `/events` للتحديث.**

## قواعد قراءة تهمّ العرض

**الطوابع أرقام يونكس بالثواني (UTC).** اعرضها ساعةً لا رقمًا:
`1785686270.237` تُقرأ `15:51:37`.

**المعرّفات (`trace_id`) طويلة وليست للعرض.** أخفها أو اطوها.

**`source` رقم الذرّة الناشرة** — مفيد للتشخيص، ليس للمستخدم.

**الأرقام النقدية تأتي كاملة بقروشها.** لا تقصّها بالتقريب: حساب من مئة
ألف يفقد معناه إن عُرض بستّ خانات.

**الحدث الغائب من `events` لم يصل بعد.** والفرق بين «صفر» و«لم يصل» هو
الفرق بين معلومة وغيابها — فلا تعرض صفرًا مكان الغياب.

## ما يفيد عرضه بارزًا

**هذه ليست تصميمًا، بل ما يُسأل عنه أوّلًا حين يصمت شيء:**

```
هل الطرفان متّصلان        platform.terminal_state.bridge_beat وعمره
هل التداول مسموح          platform.terminal_state.trade_allowed
كم ذرّة تعمل              dashboard.system.state.running
هل المفتاح منقلب          risk.unified.kill_switch_state
كم مركزًا مفتوحًا          platform.positions.state.open_count
الربح العائم              platform.positions.state.floating_pnl
```

## ما لا تفعله الواجهة

**لا تقبل أوامر.** هي قراءة فقط. التحكّم — إيقاف، إعادة تشغيل، صفقة
يدوية — يمرّ ببوّابة أوامر لم تُبنَ بعد.

**لا تحفظ تاريخًا.** اللقطة هي الحاضر. التاريخ في قاعدة النظام.

**لا تعرف شيئًا عن التصميم.** ترسل بيانات، والباقي عندك.

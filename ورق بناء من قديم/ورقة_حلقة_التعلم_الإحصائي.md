# ورقة قرار — حلقة التعلّم الإحصائي (Calibration Loop)

**الحالة: مسجَّلة · لم تُنفَّذ**
**التاريخ: 2026-08-01**
**القرار من: محمد رزوق**

---

## القرار

**قسم الاحتمالات موجود ليتعلّم من أخطائه، لا ليحسب من أرقام ثابتة.**

**والحلقة تُغلق: من التوقّع، إلى النتيجة، إلى قياس الخطأ، إلى تصحيح الرقم.**

---

## الحالة كما هي — بالفحص لا بالتقدير

### الحلقة مبنيّة 80% وتقف قبل خطوتها الأخيرة

```
351 ينتج احتمالًا
  ↓  probability.trend_model_updated
357 يدمج التسعة
  ↓  probability.models_merged  ← يحمل models بقيمة كل نموذج
359 يجمع الثقة
  ↓  probability.confidence_aggregated
360 يقيس الدقّة مقابل النتيجة
  ↓  probability.model_accuracy_tracked
361 يكشف الانحراف بنافذتين
  ↓  probability.model_drift_detected
367 يطلب المعايرة
  ↓  model.recalibration.requested
350 · 466 يستقبلان الطلب
  ✗  ولا أحد يعاير
```

### ما وجدته في الكود

**351 — الرقم مكتوب في الكود:**

```python
_PROBABILITY_MAP = {
    "UPTREND":   {"up": 0.7, "down": 0.3},
    "DOWNTREND": {"up": 0.3, "down": 0.7},
    "RANGE":     {"up": 0.5, "down": 0.5},
}
```

**`config = {}`** — لا معامل واحد قابل للضبط. **هذا بالضبط ما يجب أن يصير معايَرًا:** لو تبيّن أن الاتجاه الصاعد ينجح 0.58 لا 0.70، الرقم يُصحَّح.

**360 — ثلاثة عيوب تمنع المعايرة:**

| العيب | الأثر |
|---|---|
| يقرأ من **359** (الثقة المدموجة) لا من **357** | لا يعرف أيّ نموذج قال ماذا |
| يهمل `confidence` ويقرأ `bias` وحده | نموذج قال 0.9 وأخطأ يُحسب مثل من قال 0.55 |
| `correct / total` تراكمي أبديًا | بعد ألف صفقة، تغيّر السوق لا يظهر |

**361 — سليم ولا يحتاج تعديلًا:**

```python
older_half  = آخر عشر قبل الأخيرة
recent_half = آخر عشر
if older_accuracy - recent_accuracy > 0.2 → انحراف
```

**نافذة متحرّكة حقيقية ومقارنة فترتين. وهو ما ينقص 360.**

**367 — يمرّر فقط.** يستقبل الانحراف وينشر الطلب بلا هوية نموذج.

## التصحيح — بالترتيب، وكل مرحلة تبني بيانات التالية

### ① الأثر أولًا — بلا هذا لا معنى لما بعده

**اليوم كل حدث يحمل `trace_id` عشوائيًا جديدًا:**

```
market.tick  →  a22a644b
candle       →  00934e36   ← أثر مختلف
signal       →  aaedc6c3   ← أثر مختلف
decision     →  a663c880   ← أثر مختلف
```

**فالنظام يسجّل 250 حدثًا بلا رابط بينها. والإسناد مستحيل: 360 لا يستطيع ربط توقّع بنتيجته مهما بُني فوقه.**

**مقيس بالتشغيل:** أربعة معرّفات لسلسلة واحدة.

**والإصلاح سطران في الناقل — وهو بند كسر تجميد مسجَّل في ورقته.**

**وبعدهما:**

```
market.tick  →  a22a644b   الجذر
candle       →  a22a644b   أبوه market.tick
signal       →  a22a644b   أبوه candle
decision     →  a22a644b   أبوه signal
order        →  a22a644b   أبوه decision
```

**شجرة سببية لا كيس أحداث.**

### ② تخزين السلسلة في 707

**707 يحفظ القرارات صفوفًا منفصلة. المطلوب أن يحفظها شجرة:**

```
لكل trace_id:
   الأحداث · ترتيبها · من أنتجها · مخرجاتها · أسبابها · النتيجة
```

**فيصير سؤال «من خفّض الثقة؟» قابلًا للإجابة بعد شهر.**

### ③ النتيجة الافتراضية — وهذا أهم ما في الورقة

**اليوم 360 يقيس مقابل `market.outcome.realized` — أي الصفقات المنفَّذة وحدها.**

**والصفقة لا تُنفَّذ إلا بعد خمسة فلاتر و516 و508.**

**فالنموذج يتعلّم من عيّنة مُنقّاة لا من توقّعاته:**

- قال 0.9 ورفضه فلتر التوقيت → **لا يعرف أبدًا إن كان محقًّا**
- الدقّة المقيسة أعلى من الحقيقية دائمًا — **تحيّز اختيار**
- **والفلاتر لا تتعلّم إطلاقًا:** ترفض ولا تعرف إن كان الرفض صحيحًا

**المطلوب: ذرّة تقيس كل إشارة — منفَّذة أو مرفوضة — بحركة السعر بعد نافذة ثابتة.**

```
إشارة → رُفضت → بعد النافذة: ماذا حدث للسعر؟
                              → لو دخلنا، هل كنّا سنربح؟
                              → هل كان الرفض صحيحًا؟
```

**والفرق في حجم العيّنة: خمس وعشرون صفقة باليوم مقابل مئات الإشارات.**

**وبهذا يصير للفلتر بطاقة أداء:**

```
508  منع 87% من الخاسرة   ← ممتاز
452  رفض 18% من الرابحة   ← يستحقّ مراجعة
```

### ④ فصل القياس بالنموذج

**360 يشترك بـ`probability.models_merged` من 357 بدل 359** — سطر في المانيفست، لا تعديل عقد 359.

**ويخزّن لكل توقّع:**

```
source           رقم الذرّة — وهو هوية النموذج، لا حقل جديد
symbol
predicted_confidence
predicted_direction
actual_outcome
trace_id
timestamp
```

**ولكل نموذج على حدة:**

```
rolling_accuracy      نافذة متحرّكة لا تراكم أبدي
calibration_error     |المتوقَّع − المحقَّق|
sample_size
```

**ملاحظة مقصودة: لا حقل `model_id` ولا `strategy_id`.**

`source` هو الهوية: 351 ينشر `probability.trend_model_updated` بـ`source: 351`. **وإضافة هويّة ثانية تعطي جوابين لسؤال واحد، وحين يختلفان لا يُعرف أيّهما الصحيح.** ونفس المنطق الذي رفضنا به إعادة حساب الانكشاف في 500.

### ⑤ رسالة 367 تحمل الهوية

**بدل طلب مجرّد:**

```
source                أي نموذج
symbol
reason                drift | calibration
current_accuracy
current_calibration
recommended_adjustment
timestamp
trace_id
```

**فالطلب يصير موجَّهًا لا عامًّا.**

### ⑥ الذرّة الناقصة — 369 منفّذ المعايرة

**الرقم 369 حرّ ومؤكَّد: المبنيّ 350–368 بلا فجوة.**

```
model.recalibration.requested
          ↓
      يقرأ أداء النموذج
          ↓
      يعدّل المعامل ضمن الحدّ
          ↓
      يحفظ النسخة (706)
          ↓
      model.updated  →  351 يقرأ معامله الجديد
```

### ⑦ 351 يقرأ معاملات قابلة للتعديل

**`_PROBABILITY_MAP` ينتقل من الكود إلى `config`، ويُحدَّث من `model.updated`.**

### ⑧ الحماية — بلا هذه لا تُنفَّذ الورقة أصلًا

```
sample_size < 30        →  لا معايرة
تعديل واحد كل 50 صفقة   →  حدّ أدنى بين تعديلين
±5% لكل تعديل           →  سقف التغيير
```

**بدونها يعاير النظام نفسه على ضوضاء ويتأرجح.**

### ⑨ سجلّ المعايرات

```
source · old_value · new_value · reason
accuracy_before · accuracy_after · timestamp · trace_id
```

**كل تعديل قابل للتتبّع والتراجع.**

## فجوة لم تُحسم — وهي الأخطر في التنفيذ

**النموذج المعايَر يضيع عند إعادة التشغيل.**

**بنية الحفظ مبنيّة كاملة:** 364 مستودع · 365 محمّل · 366 مقارن · 368 سجلّ نسخ · 706 مخزن.

**لكن `model.load_requested` لا ينشره أحد.** ولا نموذج من 351–358 يسمع `model.*` إطلاقًا.

**فلو نُفّذت الورقة بلا هذا: النظام يتعلّم كل يوم وينسى كل صباح.**

**المطلوب: 369 أو 351 يطلب التحميل عند الإقلاع.** إضافة صغيرة تُغلق الحلقتين معًا.

---

## ما لم يُحسم بعد

| البند | الحالة |
|---|---|
| نافذة قياس النتيجة الافتراضية (كم شمعة بعد الإشارة) | لم تُحدَّد |
| نموذج واحد لكل الرموز أم لكل رمز على حدة | لم يُحسم |
| هل تُعاير الفلاتر أيضًا أم النماذج وحدها | لم يُحسم |
| من يطلب تحميل النموذج عند الإقلاع | لم يُحسم |
